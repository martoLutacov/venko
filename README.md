# Бати Венко

Подарък за Венелин Станчев – Бати Венко. С обич, уважение и благодарност от Марто.

## Как да го отвориш
Отвори `index.html` в браузър (или го пусни през GitHub Pages). Няма нужда от build.
Ако го отваряш локално и видеата не тръгват, пусни малък сървър в папката:

```
python3 -m http.server
```
и отвори http://localhost:8000

## Какво къде е
- `index.html` – целият сайт. Всички текстове за редакция са отбелязани с `[PLACEHOLDER]`.
- Редът на снимките и видеата в слайдшоуто е в масива `SHOW` в края на `index.html`.
- `assets/photos/` – снимките (оптимизирани), `assets/video/` – видеата (без звук, музиката върви отгоре),
  `assets/audio/music.mp3` – музиката.
- `assets/tailwind.css` и `assets/vendor/lucide.min.js` – локални копия, за да работи и без интернет.
